# 2+1 相移法替代四步相移

实测数据是垂直条纹 `FSM_vertical_f0_f150`，频率 **0, 1, …, 150 Hz，共 151 个**。每个像素沿这 151 个频率做 FFT，得到投影仪**列**坐标。这批图没有水平条纹，所以没有投影仪行坐标。

复数定义与 `FSM_decode_core.py` 相同。四步为 `C4 = (I0-I2) + j(I3-I1)`。2+1 用该频率四帧平均 `A4 = (I0+I1+I2+I3)/4` 作背景，`C21 = 2*((I0-A4) + j(A4-I1))`。后面的 FFT 长度、峰值搜索和亚像素公式两边相同。

## 最终结论

**可以替代。** 在四步峰值不低于 1.5 的有效像素上，2+1 与四步得到的投影仪列坐标一致。2,535,906 个有效像素里，99.9999% 的亚像素绝对差不超过 1 列；绝对差大于 1 列的只有 2 个像素。

完整表在 [有效像素列坐标误差表.md](2plus1_逐像素频谱/有效像素列坐标误差表.md)。

| 项目 | 数值 |
| --- | ---: |
| 全图像素 | 5,013,504 |
| 有效像素（四步峰值 ≥ 1.5） | 2,535,906（50.58%） |
| 整数列号相同 | 2,506,860（98.85%） |
| 整数列号差 1 | 29,044（1.15%） |
| 整数列号差超过 1 | 2（0.0001%） |
| 亚像素绝对差 ≤ 0.5 列 | 98.85% |

| 绝对差 99% 分位 | 0.993 列 |
| 绝对差 > 1 列 | 2 个像素 |
| 绝对差 > 5 列 | 2 个像素 |

## 整数列号差 1 的原因与可否替代

- 并不是出现了第二个物理主峰，而是**同一个主瓣**落在两个相邻 FFT bin 之间，两格幅值几乎相等（例如 1422/1423 仅差约 0.0003）。
- 2+1 相对四步的微小复数残差会改变相邻两格的高低关系，`argmax` 可能从 1423 变为 1422；亚像素质心仍在同一主瓣上（亚像素差约 1 列以内）。
- 在峰值 ≥ 1.5 的有效像素上：98.85% 整数列完全相同，1.15% 整数差 1 列，0.0001% 差超过 1 列。
- 若验收标准是 **「整数列必须 100% 一致」**，当前 2+1（A4 背景）**尚不满足**；若接受 **亚像素 ≤ 1 列**，则 99.9999% 满足，可继续用于 FSM 列坐标解码与重建（`disp_*.npy` 格式不变）。

整数列号差 1 的那 1.15%，亚像素位置仍落在相邻两列的交界上，绝对差不超过 1 列。它们不是被另一个小峰抢走了主峰。

本次测试背景仍可用「每频率 A4」或「共享灰图」两种来源；主线 `FSM_decode_core.py` 已通过 `PhaseShiftDemodulator` 在配置中切换。

## 以前两张图为什么容易看错

`图/02_复数剖线.png` 画的是**频率 16、图像第 446 行、沿 x 的空间变化**。那是某一个频率上的一条线，不是一个像素在 151 个频率里的变化。仿真附件里用这种图，是因为当时只生成了一张频率的模拟图。现在的主证据是上面的逐像素频率曲线。

`图/01_复数绝对误差.png` 和 `图/03_全图列坐标差.png` 标题里的“每 4 像素”，只是存图时沿 x、y 各隔 4 个点取了一个显示样本。计算仍是逐像素做的，并不是每 4 个像素合成一个结果。这次的误差表不再做这种降采样，2,535,906 个有效像素每个都进了统计。

## 采集张数说明

- **A4 合成 2+1**：仍读 4M 张图，仅在解调时用四帧平均作背景，采集张数未减少；用于与四步 A/B 对比。
- **原生 2+1**：配置 `phase_shift_mode="two_plus_one"`、`background_mode="shared_gray"`，目录布局为 `0.png` 共享灰图 + 每频 2 张 I0/I1（共 2M+1 张），见 `FSM_decode_example.py` 配置区。
