## 📖 核心概念速查

### FSA是什么？

**FSA (Frequency Shift Analysis)** = 频移法

- 投影一系列**频率递增**的正弦条纹
- 每个频率投影**4张相移图**（0°, 90°, 180°, 270°）
- 通过**DFT（傅里叶变换）**解码出投影仪坐标

### 核心公式

```bash
对于相机像素 (xc, yc)：

1. 采集 M 个频率的图像：I0, I1, I2, I3 (共 M×4 张)

2. 构造复数信号：
   D[k] = (I0[k] - I2[k]) + j*(I3[k] - I1[k])

3. DFT变换：
   C = FFT(D)

4. 峰值检测：
   投影仪坐标 = argmax(|C|)
```

### 关键参数说明

| 参数 | 说明 | 典型值 | 如何确定 |
|------|------|--------|----------|
| `projector_width` | 投影仪宽度 | 1024 | 查看投影仪分辨率 |
| `projector_height` | 投影仪高度 | 768 | 查看投影仪分辨率 |
| `num_frequencies` | 采集频率数 | 121 | 通常为投影仪分辨率的1/8 |
| `frequency_step` | 频率步长 | 1.0 | 1.0Hz标准，0.5Hz精细 |
| `block_size` | 分块大小 | 100 | 根据内存调整 |
| `peak_threshold` | 峰值阈值 | 0.5-1.0 | 根据质量要求调整 |

### 🆕 频率步长功能 (v2.0新增)

**频率步长**是控制条纹频率间隔的重要参数：

| 步长 | 频率范围 | 图像数量 | 适用场景 |
|------|----------|----------|----------|
| 1.0 Hz | 0, 1, 2, ..., 150 Hz | 151×4 = 604张 | 标准精度，快速处理 |
| 0.5 Hz | 0, 0.5, 1.0, ..., 150 Hz | 301×4 = 1204张 | 高精度，更好质量 |
| 2.0 Hz | 0, 2, 4, ..., 150 Hz | 76×4 = 304张 | 快速预览，低精度 |

**优势对比**：
- ✅ **0.5Hz步长**: 更高频率分辨率，更好噪声抑制，检测更小相位变化
- ⚠️ **代价**: 2倍图像数量，2倍处理时间，2倍存储空间

## 🎯 核心API速查

### FSADecoder 类

```python
from FSM_decode_core import FSADecoder

# 初始化 (v2.0支持频率步长)
decoder = FSADecoder(
    projector_width,     # 投影仪宽度
    projector_height,    # 投影仪高度
    frequency_step=1.0   # 频率步长 (新增参数)
)

# 加载图像
images = decoder.load_images(
    image_dir,          # 图像文件夹
    num_frequencies,    # 频率数量
    use_cache=True      # 使用缓存加速
)

# 解码 (支持频谱分析)
disparity, peak, spectrum_data = decoder.decode_direction(
    images,                    # 图像数组
    direction,                 # 'hor' 或 'ver'
    num_frequencies,           # 频率数量
    block_size=100,            # 分块大小
    debug_point=None,          # 调试点 (x, y)
    spectrum_point=(1200,1000) # 频谱分析点 (新增)
)

# 保存
decoder.save_results(disparity, peak, output_dir, direction)
```

```python
import numpy as np

# 读取
disparity_ver = np.load('results/disp_ver.npy')
peak_ver = np.load('results/peak_ver.npy')

# 使用
yc, xc = 100, 200  # 相机像素
xp = disparity_ver[yc, xc]  # 对应的投影仪X坐标
quality = peak_ver[yc, xc]   # 质量评分

print(f"相机({xc},{yc}) → 投影仪X={xp:.2f}, 质量={quality:.4f}")
```

### 质量评估标准

| 峰值强度 | 质量等级 | 建议 |
|----------|----------|------|
| > 1.5 | 优秀 ⭐⭐⭐⭐⭐ | 可直接使用 |
| 1.0 - 1.5 | 良好 ⭐⭐⭐⭐ | 可使用 |
| 0.5 - 1.0 | 中等 ⭐⭐⭐ | 谨慎使用 |
| < 0.5 | 较差 ⭐ | 建议过滤 |

```python
# 过滤低质量像素
threshold = 0.5
valid_mask = peak_ver >= threshold
disparity_filtered = disparity_ver.copy()
disparity_filtered[~valid_mask] = np.nan
```

## ⚠️ 常见问题快速解决

### 问题1：FileNotFoundError

**错误信息**：

```bash
FileNotFoundError: 图像文件不存在: ./data/ver/0.png
```

**解决方法**：

1. 检查路径是否正确
2. 确认图像文件是否存在
3. 修改 `fsa_decode_example.py` 中的路径配置

### 问题2：内存不足

**错误信息**：

```bash
MemoryError: Unable to allocate array
```

**解决方法**：

```python
# 减小 block_size
disparity, peak = decoder.decode_direction(
    images, 'ver', 121, 
    block_size=50  # 从100改为50
)
```

### 问题3：解码结果噪点多

**现象**：视差图出现很多噪点

**解决方法**：

```python
# 提高质量阈值
vis.visualize_disparity('ver', peak_threshold=1.0)  # 从0.5改为1.0
```

### 问题4：import错误

**错误信息**：

```bash
ImportError: cannot import name 'FSADecoder'
```

**解决方法**：

```bash
# 确保在正确的目录下运行
cd E:\在校学习\fsa

# 或者添加路径
import sys
sys.path.append(r'E:\在校学习\fsa')
from FSM_decode_core import FSADecoder  # 注意文件名更新
```

### 问题5：频率步长配置错误

**错误现象**：频谱可视化中频率轴显示不正确

**解决方法**：

```python
# 确保频率数量与步长匹配
# 要达到150Hz最高频率：

# 1.0Hz步长：需要151个频率 (0, 1, 2, ..., 150)
decoder = FSADecoder(1920, 1080, frequency_step=1.0)
NUM_FREQUENCIES = 151

# 0.5Hz步长：需要301个频率 (0, 0.5, 1.0, ..., 150)  
decoder = FSADecoder(1920, 1080, frequency_step=0.5)
NUM_FREQUENCIES = 301

# 检查配置
max_freq = (NUM_FREQUENCIES - 1) * FREQUENCY_STEP
print(f"最高频率: {max_freq} Hz")  # 应该是150Hz
```

### 问题6：0.5Hz步长内存不足

**错误现象**：使用0.5Hz步长时内存溢出

**解决方法**：

```python
# 方法1：启用低内存模式
disparity, peak, spectrum = decoder.decode_direction(
    images, 'hor', 301,
    low_memory=True  # 启用低内存模式
)

# 方法2：减小分块大小
disparity, peak, spectrum = decoder.decode_direction(
    images, 'hor', 301,
    block_size=50    # 从100减小到50
)
```

## 🎬 完整示例：从零到结果

假设你有一组新采集的条纹图像，完整流程如下：

```python
"""
完整的FSA解码流程示例
"""
import numpy as np
from fsa_decode_core import FSADecoder
from fsa_visualize import FSAVisualizer
import os

# ========== 配置 ==========
PROJECTOR_SIZE = (1920, 1080)  # (宽, 高)
NUM_FREQ = 151                 # 频率数量
FREQUENCY_STEP = 1.0           # 频率步长 (Hz)
DATA_DIR = r"E:\在校学习\fsa\data\my_object"
OUTPUT_DIR = r"E:\在校学习\fsa\results\my_object"

# ========== 解码 ==========
print("="*60)
print("开始FSA解码 (v2.0)")
print("="*60)
print(f"频率步长: {FREQUENCY_STEP} Hz")
print(f"频率数量: {NUM_FREQ}")
print(f"最高频率: {(NUM_FREQ-1) * FREQUENCY_STEP} Hz")
print(f"总图像数: {NUM_FREQ * 4}")

decoder = FSADecoder(*PROJECTOR_SIZE, frequency_step=FREQUENCY_STEP)

# 解码水平方向
print("\n[1/2] 解码水平条纹...")
images_h = decoder.load_images(f"{DATA_DIR}/hor", NUM_FREQ)
disp_h, peak_h = decoder.decode_direction(images_h, 'hor', NUM_FREQ)
decoder.save_results(disp_h, peak_h, OUTPUT_DIR, 'hor')

# 解码垂直方向
print("\n[2/2] 解码垂直条纹...")
images_v = decoder.load_images(f"{DATA_DIR}/ver", NUM_FREQ)
disp_v, peak_v = decoder.decode_direction(images_v, 'ver', NUM_FREQ)
decoder.save_results(disp_v, peak_v, OUTPUT_DIR, 'ver')

# ========== 质量评估 ==========
print("\n" + "="*60)
print("质量评估")
print("="*60)

quality = np.minimum(peak_h, peak_v)
total = quality.size

print(f"\n总像素数: {total}")
print(f"优秀 (>1.5): {np.sum(quality>1.5)} ({np.sum(quality>1.5)/total*100:.1f}%)")
print(f"良好 (1.0-1.5): {np.sum((quality>1.0)&(quality<=1.5))} ({np.sum((quality>1.0)&(quality<=1.5))/total*100:.1f}%)")
print(f"中等 (0.5-1.0): {np.sum((quality>0.5)&(quality<=1.0))} ({np.sum((quality>0.5)&(quality<=1.0))/total*100:.1f}%)")
print(f"较差 (<0.5): {np.sum(quality<=0.5)} ({np.sum(quality<=0.5)/total*100:.1f}%)")

# ========== 可视化 ==========
print("\n" + "="*60)
print("生成可视化结果")
print("="*60)

vis = FSAVisualizer(OUTPUT_DIR)

# 保存所有可视化
os.makedirs(f"{OUTPUT_DIR}/visualizations", exist_ok=True)

vis.visualize_disparity('hor', 0.5, f"{OUTPUT_DIR}/visualizations/disp_hor.png")
vis.visualize_disparity('ver', 0.5, f"{OUTPUT_DIR}/visualizations/disp_ver.png")
vis.visualize_statistics(f"{OUTPUT_DIR}/visualizations/statistics.png")
vis.visualize_correspondence_map(0.5, f"{OUTPUT_DIR}/visualizations/correspondence.png")

print("\n" + "="*60)
print("✅ 完成！")
print("="*60)
print(f"\n结果保存在: {OUTPUT_DIR}")
print(f"可视化保存在: {OUTPUT_DIR}/visualizations")
```

保存为 `my_decode_script.py`，然后运行：

```bash
python my_decode_script.py
```
