## 一、前置条件

### ✅ 必须完成的准备工作

#### 1. 完成相机-投影仪标定
- 文件：`标定结果.txt`
- 包含相机内参、投影仪内参、旋转矩阵、平移向量

#### 2. 完成FSA解码
必需文件（位于 `results/fsa_decode/`）：
- `disp_hor.npy` - 水平视差图
- `disp_ver.npy` - 垂直视差图
- `peak_hor.npy` - 水平峰值图
- `peak_ver.npy` - 垂直峰值图

运行解码：
```bash
python FSM_decode_example.py
```

#### 3. 安装Python库
```bash
pip install numpy opencv-python open3d
```

## 二、快速上手

### 🎯 最简单的使用方式

如果文件都在默认位置，直接运行：

```bash
python FSM_reconstruct_example.py
```

程序会自动：
1. ✅ 加载标定参数
2. ✅ 加载视差图
3. ✅ 执行三维重建
4. ✅ 保存点云 `pointcloud_fsa.ply`
5. ✅ 显示3D可视化窗口

### 🔧 修改配置

打开 `FSM_reconstruct_example.py`，找到配置参数区域（第28-79行）：

```python
if __name__ == "__main__":
```

## 三、配置参数详解

### 1️⃣ CALIBRATION_FILE - 标定文件路径

```python
CALIBRATION_FILE = "标定结果.txt"
```

**说明**：相机-投影仪标定结果文件

**修改示例**：
```python
CALIBRATION_FILE = r"D:\data\标定结果.txt"  # 绝对路径
```

---

### 2️⃣ CAMERA_IMAGE_SIZE - 相机图像尺寸

```python
CAMERA_IMAGE_SIZE = (2448, 2048)  # (宽, 高)
```

**说明**：必须与采集图像时的分辨率一致

**如何确定**：
```python
import numpy as np
disp = np.load("results/fsa_decode/disp_ver.npy")
height, width = disp.shape
CAMERA_IMAGE_SIZE = (width, height)
```

⚠️ **注意**：格式是 (宽, 高)，不是 (高, 宽)

---

### 3️⃣ PROJECTOR_WIDTH / PROJECTOR_HEIGHT - 投影仪分辨率

```python
PROJECTOR_WIDTH = 1920
PROJECTOR_HEIGHT = 1080
```

**说明**：必须与FSA解码时使用的分辨率一致

**常见分辨率**：
- 1920 × 1080 (Full HD)
- 1280 × 800 (WXGA)
- 1024 × 768 (XGA)

---

### 4️⃣ RESULT_DIR - 解码结果文件夹

```python
RESULT_DIR = "results/fsa_decode"
```

**说明**：存放FSA解码结果的文件夹

**修改示例**：
```python
RESULT_DIR = r"D:\data\fsa_results"  # 绝对路径
```

---

### 5️⃣ OVERSAMPLE - 过采样倍数 ⭐⭐⭐

```python
OVERSAMPLE = 4
```

**说明**：
- 解码时使用的过采样倍数
- **必须与FSA解码时的设置完全一致**
- 用于将视差图坐标转换为实际投影仪坐标

**计算公式**：
```
实际投影仪坐标 = 视差图数值 / OVERSAMPLE
```

⚠️ **重要**：如果设置错误，重建的点云会严重变形

---

### 6️⃣ PEAK_LIMIT - 峰值阈值 ⭐⭐⭐

```python
PEAK_LIMIT = 0.8
```

**说明**：
- 质量过滤阈值
- 只有峰值强度 ≥ 此阈值的像素才会被用于重建
- **这是控制点云质量的关键参数**

**阈值选择指南**：

| 阈值 | 点云数量 | 点云质量 | 适用场景 |
|-----|---------|---------|---------|
| 0.5 | 多 | 中等 | 包含更多点，可能有噪声 |
| 0.8 | 中等 | 高 | **推荐**，平衡质量和数量 |
| 1.0 | 少 | 很高 | 只保留最可靠的点 |
| 1.5 | 很少 | 极高 | 高精度测量 |

**使用建议**：
```python
# 初次重建，想看到更多点
PEAK_LIMIT = 0.5

# 一般重建（推荐）
PEAK_LIMIT = 0.8

# 高精度测量
PEAK_LIMIT = 1.0

# 点云太少，降低阈值
PEAK_LIMIT = 0.3
```

---

### 7️⃣ WHITE_IMAGE_PATH - 白光图像路径 ⭐

```python
WHITE_IMAGE_PATH = None
```

**说明**：
- 用于给点云赋予真实颜色
- 如果设为 `None`，点云将使用默认灰色

**使用场景**：

#### 场景1：不需要颜色（默认）
```python
WHITE_IMAGE_PATH = None
```
- 点云为灰色
- 适合快速测试

#### 场景2：使用白光图像的颜色
```python
WHITE_IMAGE_PATH = "white_light.png"
# 或
WHITE_IMAGE_PATH = r"F:\data\white_light.png"
```
- 点云将显示物体的真实颜色
- 需要在采集时拍摄一张白光照明下的图像

**白光图像要求**：
- ✅ 与条纹图像在同一位置拍摄
- ✅ 使用白光照明（无条纹）
- ✅ 图像尺寸与相机图像一致

---

### 8️⃣ MIN_DISTANCE / MAX_DISTANCE - 距离过滤

```python
MIN_DISTANCE = None    # 最小距离限制（mm）
MAX_DISTANCE = None    # 最大距离限制（mm）
```

**说明**：根据点到相机的距离过滤点云

**使用场景**：

```python
# 场景1：不过滤（默认）
MIN_DISTANCE = None
MAX_DISTANCE = None

# 场景2：过滤太近的点
MIN_DISTANCE = 500
MAX_DISTANCE = None

# 场景3：过滤太远的点
MIN_DISTANCE = None
MAX_DISTANCE = 2000

# 场景4：限制距离范围
MIN_DISTANCE = 500
MAX_DISTANCE = 2000  # 只保留500-2000mm范围内的点
```

---

### 9️⃣ OUTPUT_PLY - 输出文件路径

```python
OUTPUT_PLY = "pointcloud_fsa.ply"
```

**说明**：输出点云文件的名称

**修改示例**：
```python
# 使用相对路径
OUTPUT_PLY = "results/my_pointcloud.ply"

# 使用绝对路径
OUTPUT_PLY = r"D:\output\pointcloud.ply"

# 添加时间戳
from datetime import datetime
timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
OUTPUT_PLY = f"pointcloud_{timestamp}.ply"
```

## 四、常见问题

**错误信息**：
```
❌ 错误: 标定文件不存在: 标定结果.txt
```

**解决方法**：
```python

import os
print(os.path.exists("标定结果.txt"))

# 2. 使用绝对路径
CALIBRATION_FILE = r"D:\完整路径\标定结果.txt"
```

---

### Q2：程序报错"视差图文件不存在"

**错误信息**：
```
❌ 错误: 以下文件不存在:
   - 水平视差图: results/fsa_decode/disp_hor.npy
```

**解决方法**：
```bash
# 1. 先运行FSA解码
python FSM_decode_example.py

# 2. 检查解码结果位置，修改 RESULT_DIR
RESULT_DIR = "你的解码结果文件夹"
```

---

### Q3：重建的点云数量太少

**现象**：
```
有效像素数: 50,000 (1.0%)  # 太少！
```

**解决方法**：
```python
# 方法1：降低峰值阈值
PEAK_LIMIT = 0.5  # 从0.8改为0.5

# 方法2：检查解码质量
# 运行 FSM_visualize.py 查看解码质量
```

---

### Q4：重建的点云有很多噪点

**解决方法**：
```python
# 方法1：提高峰值阈值
PEAK_LIMIT = 1.0  # 从0.8改为1.0

# 方法2：使用距离过滤
MIN_DISTANCE = 500
MAX_DISTANCE = 2000
```

---

### Q5：点云的尺寸不对

**原因**：
- `OVERSAMPLE` 参数设置错误
- 标定参数不正确

**解决方法**：
```python
# 检查 OVERSAMPLE 是否与解码时一致
OVERSAMPLE = 4  # 必须与解码时相同

# 检查投影仪分辨率是否正确
PROJECTOR_WIDTH = 1920
PROJECTOR_HEIGHT = 1080
```

---

### Q6：可视化窗口无法打开

**错误信息**：
```
❌ 可视化失败: No module named 'open3d'
```

**解决方法**：
```bash
pip install open3d
```

---

### Q7：点云没有颜色（全是灰色）

**原因**：
- 没有配置 `WHITE_IMAGE_PATH`
- 或白光图像加载失败

**解决方法**：
```python
# 配置白光图像路径
WHITE_IMAGE_PATH = "white_light.png"
```

## 五、输出结果说明

### 点云文件 - pointcloud_fsa.ply

**文件格式**：PLY (Polygon File Format)

**包含内容**：
- 每个点的3D坐标 (X, Y, Z)，单位：毫米(mm)
- 每个点的颜色 (R, G, B)，范围：0-255

**如何打开**：

#### 方法1：使用CloudCompare（推荐）
```
下载: https://www.cloudcompare.org/
打开: File → Open → 选择 pointcloud_fsa.ply
```

#### 方法2：使用Python
```python
import open3d as o3d
import numpy as np

# 读取点云
pcd = o3d.io.read_point_cloud("pointcloud_fsa.ply")

# 显示点云
o3d.visualization.draw_geometries([pcd])

# 获取点云数据
points = np.asarray(pcd.points)
colors = np.asarray(pcd.colors)

print(f"点云数量: {len(points)}")
print(f"X范围: [{points[:, 0].min():.2f}, {points[:, 0].max():.2f}] mm")
```

## 六、程序执行流程

程序运行时会自动执行6个步骤：

### 步骤1：检查标定文件
验证标定文件是否存在

### 步骤2：加载视差图
- 检查所有必需的 `.npy` 文件
- 加载白光图像（如果配置了）
- 加载视差图和峰值图

### 步骤3：创建三维重建器
- 读取标定文件
- 初始化重建器

### 步骤4：执行三维重建 ⭐
- 根据峰值阈值过滤低质量像素
- 将视差图转换为投影仪坐标
- 使用三角化计算3D坐标
- 提取点云颜色

### 步骤5：保存点云
将点云保存为PLY格式文件

### 步骤6：可视化点云
使用Open3D显示3D点云

**可视化操作**：
- 🖱️ 左键拖动：旋转视角
- 🖱️ 右键拖动：平移视角
- 🖱️ 滚轮：缩放
- ⌨️ Q键：退出
