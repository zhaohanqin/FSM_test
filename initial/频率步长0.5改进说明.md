# 频率步长为0.5时的解码改进说明

## 📋 问题分析

### 当前代码的问题

当频率步长为1.0时，代码可以正常工作：
- 频率数量 M = 投影仪分辨率 N（例如：M=121, N=1024或768）
- DFT长度使用 N，频率索引直接对应投影仪坐标
- 例如：频率索引 k=50 直接对应投影仪坐标 50

当频率步长为0.5时，会出现问题：
- 频率数量 M = 2×N（例如：M=242, N=1024）
- 但代码仍然使用 N 作为DFT长度，导致：
  1. **信息丢失**：只使用了前N个频率，丢失了后N个频率的信息
  2. **频率分辨率不足**：无法充分利用0.5Hz的精细频率步长
  3. **坐标映射错误**：频率索引无法正确映射到投影仪坐标

### 具体问题示例

假设投影仪宽度 W=1024，频率步长=0.5：
- 频率数量 M = 242（频率范围：0, 0.5, 1.0, ..., 120.5 Hz）
- 原代码使用 N=1024 作为DFT长度
- 问题：只处理了前1024个频率点，但实际只有242个频率，导致：
  - 频谱分辨率不足
  - 无法正确映射频率索引到投影仪坐标

## 🔧 改进方案

### 改进点1：DFT长度使用频率数量M

**原代码（错误）：**
```python
C = np.abs(np.fft.fft(D[:,ty:ey,tx:ex], N, axis=0))  # 使用投影仪分辨率N
```

**改进后（正确）：**
```python
if frequency_step == 1.0:
    fft_length = N  # 标准情况：M=N
else:
    fft_length = M  # 频率步长不为1.0时：使用频率数量M

C = np.abs(np.fft.fft(D[:,ty:ey,tx:ex], n=fft_length, axis=0))
```

**原因：**
- 当frequency_step=0.5时，M=2×N，需要使用M作为DFT长度
- 这样可以充分利用所有频率信息，获得更高的频率分辨率

### 改进点2：频率索引到投影仪坐标的映射

**原代码（错误）：**
```python
disparity[ty:ey,tx:ex] = np.argmax(C, axis=0)  # 直接使用频率索引
```

**改进后（正确）：**
```python
freq_index = np.argmax(C, axis=0)  # 频率索引

if frequency_step == 1.0:
    # 标准情况：频率索引直接等于投影仪坐标
    disparity[ty:ey,tx:ex] = freq_index
else:
    # 频率步长不为1.0时：需要映射
    # 映射公式：投影仪坐标 = 频率索引 * (投影仪分辨率 / 频率数量)
    coord_scale = N / M
    disparity[ty:ey,tx:ex] = freq_index * coord_scale
```

**映射公式说明：**
- 频率索引范围：[0, M-1]
- 投影仪坐标范围：[0, N-1]
- 映射比例：`coord_scale = N / M`
- 例如：M=242, N=1024, coord_scale = 1024/242 ≈ 4.23
  - 频率索引 k=121 → 投影仪坐标 = 121 × 4.23 ≈ 512

### 改进点3：峰值强度归一化

**原代码：**
```python
peak[ty:ey,tx:ex] = np.max(C, axis=0) / N
```

**改进后：**
```python
peak[ty:ey,tx:ex] = np.max(C, axis=0) / fft_length
```

**原因：**
- 归一化应该除以DFT长度（fft_length），而不是固定的N
- 当frequency_step=0.5时，fft_length=M，确保峰值强度在[0,1]范围内

### 示例2：精细频率步长（0.5）

```python

# 解码（自动应用改进方案）

```

## ⚠️ 注意事项

1. **图像数量要求**：
   - frequency_step=1.0: 需要 M×4 张图像（例如：121×4=484张）
   - frequency_step=0.5: 需要 M×4 张图像（例如：242×4=968张，是原来的2倍）

2. **内存占用**：
   - frequency_step=0.5时，图像数量翻倍，内存占用也翻倍
   - 建议使用分块处理（block_size）来降低内存占用

3. **处理时间**：
   - frequency_step=0.5时，处理时间约为原来的2倍
   - 但解码精度提高，特别是对于细节丰富的场景

4. **坐标精度**：
   - frequency_step=0.5时，坐标映射后可能不是整数
   - 这是正常的，表示子像素精度的投影仪坐标

## 📈 优势总结

使用频率步长0.5的改进方案后：

✅ **更高的频率分辨率**：0.5Hz vs 1.0Hz，提高2倍  
✅ **更好的噪声抑制**：更多频率点提供更好的频谱分析  
✅ **更精确的坐标映射**：充分利用所有频率信息  
✅ **向后兼容**：frequency_step=1.0时行为不变
