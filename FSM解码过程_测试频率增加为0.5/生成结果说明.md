## 一、解码结果文件（.npy文件）

FSA解码后会在 `results/fsa_decode/` 文件夹中生成6个`.npy`文件，这些是**NumPy数组文件**，包含解码的核心数据。

### 📁 文件清单

```
results/fsa_decode/
├── disp_hor.npy          # 水平方向视差图（投影仪行坐标）
├── peak_hor.npy          # 水平方向峰值强度图（质量图）
├── disp_ver.npy          # 垂直方向视差图（投影仪列坐标）
├── peak_ver.npy          # 垂直方向峰值强度图（质量图）
├── spectrum_hor.npy      # 水平方向频谱数据（特定像素点）
└── spectrum_ver.npy      # 垂直方向频谱数据（特定像素点）
```

---

### 1️⃣ disp_ver.npy - 垂直视差图（投影仪列坐标）

**文件大小**：约19MB  
**数据类型**：浮点数数组  
**数组形状**：(2048, 2448) - 相机图像的高度×宽度

#### 📖 含义

这个文件存储的是**相机像素到投影仪列坐标（X坐标）的映射**。

**具体来说**：
- 数组中每个位置 `(y, x)` 对应相机的一个像素点
- 该位置的**数值**表示这个相机像素对应的**投影仪列坐标**（范围：0-1919）

#### 🔍 示例

```python
import numpy as np

# 加载数据
disp_ver = np.load('disp_ver.npy')

# 查询相机像素(1200, 1000)对应的投影仪列坐标
camera_x, camera_y = 1200, 1000
projector_x = disp_ver[camera_y, camera_x]

print(f"相机像素({camera_x}, {camera_y}) → 投影仪X坐标 = {projector_x:.2f}")
# 输出：相机像素(1200, 1000) → 投影仪X坐标 = 1232.45
```

#### 💡 用途

- **三维重建**：结合相机标定参数，将相机像素转换为三维坐标
- **对应关系查询**：快速查找任意相机像素对应的投影仪坐标
- **质量分析**：结合峰值图过滤低质量像素

### 2️⃣ peak_ver.npy - 垂直峰值强度图（质量图）

**文件大小**：约19MB  
**数据类型**：浮点数数组  
**数组形状**：(2048, 2448) - 与视差图相同

#### 📖 含义

这个文件存储的是**解码质量的评估指标**，也叫**峰值强度图**或**置信度图**。

**具体来说**：
- 数组中每个位置 `(y, x)` 对应相机的一个像素点
- 该位置的**数值**表示该像素解码的**可靠程度**
- **数值越大** = 解码质量越高 = 结果越可靠

#### 📊 数值范围与含义

| 峰值强度范围 | 质量等级 | 含义 | 建议 |
|------------|---------|------|------|
| **> 1.0** | 优秀 | 信号强、峰值尖锐、对应关系明确 | ✅ 可直接使用 |
| **0.5 - 1.0** | 中等 | 信号较弱、有一定干扰 | ⚠️ 谨慎使用 |
| **< 0.5** | 差 | 信号弱、多峰模糊、不可靠 | ❌ 建议丢弃 |

#### 🔬 物理意义

峰值强度反映了**DFT频谱的集中程度**：

```
高峰值（例如1.5）：
频谱中有一个尖锐的主峰
    |
    |      ████  ← 能量集中
    |      ████
    |______████____
        投影仪坐标
✅ 对应关系唯一明确

低峰值（例如0.3）：
频谱中能量分散
    |
    |  ██  ██  ██  ← 能量分散
    |  ██  ██  ██
    |__██__██__██__
        投影仪坐标
❌ 无法确定真实坐标
```

#### 🔍 示例

```python
import numpy as np

# 加载数据
peak_ver = np.load('peak_ver.npy')

# 查询相机像素(1200, 1000)的解码质量
camera_x, camera_y = 1200, 1000
quality = peak_ver[camera_y, camera_x]

print(f"相机像素({camera_x}, {camera_y})的解码质量 = {quality:.4f}")
# 输出：相机像素(1200, 1000)的解码质量 = 1.5234

if quality > 1.0:
    print("✅ 高质量，可靠")
elif quality > 0.5:
    print("⚠️ 中等质量，谨慎使用")
else:
    print("❌ 低质量，建议丢弃")
```

#### 💡 用途

- **质量过滤**：三维重建时只使用高质量像素
- **问题诊断**：找出解码质量差的区域，分析原因
- **自适应处理**：根据质量调整后续算法参数

### 3️⃣ disp_hor.npy - 水平视差图（投影仪行坐标）

**含义**：与 `disp_ver.npy` 类似，但存储的是**投影仪行坐标（Y坐标）**的映射。

- 数值范围：0-1079（投影仪高度）
- 用途：与 `disp_ver.npy` 结合，获得完整的2D对应关系

#### 🔍 示例

```python
# 完整的2D对应关系
disp_hor = np.load('disp_hor.npy')
disp_ver = np.load('disp_ver.npy')

camera_x, camera_y = 1200, 1000
projector_x = disp_ver[camera_y, camera_x]
projector_y = disp_hor[camera_y, camera_x]

print(f"相机像素({camera_x}, {camera_y})")
print(f"  → 投影仪像素({projector_x:.2f}, {projector_y:.2f})")
```

---

### 4️⃣ peak_hor.npy - 水平峰值强度图

**含义**：与 `peak_ver.npy` 类似，但表示**水平方向的解码质量**。

#### 💡 综合质量评估

```python
# 综合质量 = 两个方向中较差的那个
peak_hor = np.load('peak_hor.npy')
peak_ver = np.load('peak_ver.npy')

quality_combined = np.minimum(peak_hor, peak_ver)

# 高质量像素掩码
high_quality_mask = quality_combined > 1.0
print(f"高质量像素数量：{np.sum(high_quality_mask)}")
print(f"高质量像素占比：{np.sum(high_quality_mask) / high_quality_mask.size * 100:.2f}%")
```

### 5️⃣ spectrum_ver.npy - 垂直方向频谱数据

**文件大小**：约72KB  
**数据类型**：Python字典（存储为NumPy对象）

#### 📖 含义

这个文件存储的是**指定像素点的完整频谱分析数据**，用于调试和理解解码过程。

#### 📦 包含的数据

```python
spectrum_ver = np.load('spectrum_ver.npy', allow_pickle=True).item()

# 字典内容：
{
    'point': (1200, 1000),          # 分析的像素点坐标
    'direction': 'ver',             # 解码方向（垂直）
    'N': 1920,                      # DFT长度（投影仪宽度）
    'num_frequencies': 121,         # 采集的频率数量
    
    # 原始数据
    'I0': [121个数值],              # 0°相位的强度序列
    'I1': [121个数值],              # 90°相位的强度序列
    'I2': [121个数值],              # 180°相位的强度序列
    'I3': [121个数值],              # 270°相位的强度序列
    
    # 差分信号
    'Dc': [121个数值],              # I0 - I2（余弦分量）
    'Ds': [121个数值],              # I3 - I1（正弦分量）
    
    # 频谱数据
    'spectrum': [1920个数值],       # 归一化的频谱幅值
    'spectrum_raw': [1920个数值],   # 原始频谱幅值
    'spectrum_complex': [1920个复数], # 复数频谱
    'frequencies': [0, 1, 2, ..., 1919], # 频率坐标
    
    # 解码结果
    'peak_index': 1232,             # 最大峰值位置（投影仪X坐标）
    'peak_value': 4.9024            # 最大峰值强度
}
```

#### 💡 用途

- **调试**：查看解码过程的每一步
- **算法验证**：验证FSA理论模型
- **问题诊断**：分析为什么某个像素解码失败
- **频谱可视化**：生成详细的频谱分析图

| 序号 | 文件名 | 用途 |
|-----|--------|------|
| - | `spectrum_ver_x1200_y1000.png` | **大图**：8个子图的合集（第8个位置空白） |
| 1 | `_01_原始强度序列.png` | 查看采集的原始数据（I0, I1, I2, I3） |

### 📊 各图详细说明

#### 图1：原始强度序列

**显示内容**：
- X轴：频率索引 k（0-120）
- Y轴：强度值（0-255）
- 四条曲线：I0(0°)、I1(90°)、I2(180°)、I3(270°)

**如何解读**：
- ✅ **好的信号**：四条曲线平滑、周期性明显、幅值适中
- ❌ **差的信号**：曲线杂乱、饱和（接近0或255）、有突变

**示例**：
```
好的信号：
强度
 |  /\    /\    /\     ← 平滑的正弦波
 | /  \  /  \  /  \
 |/    \/    \/    \
 |____________________ 频率索引

差的信号：
强度
255|████  ███  ██      ← 过曝，饱和
 | █  █ █  █ █  █
 0|____________________ 频率索引
```

---

#### 图2：差分信号

**显示内容**：
- X轴：频率索引 k（0-120）
- Y轴：差分值
- 两条曲线：Dc = I0-I2（余弦分量）、Ds = I3-I1（正弦分量）

**物理意义**：
- 差分操作**消除了环境光和表面反射率的影响**
- 只保留了条纹的**调制信号**

**如何解读**：
- ✅ 曲线平滑、振幅大 → 调制度高，信号好
- ❌ 曲线杂乱、振幅小 → 调制度低，信号差

---

#### 图3：复数信号幅值

**显示内容**：
- X轴：频率索引 k（0-120）
- Y轴：|D| = |Dc + j·Ds|（复数信号的幅值）

**物理意义**：
- 表示每个频率的**条纹调制强度**
- 理想情况下应该在某个频率范围内较大

---

#### 图4：完整频谱（线性坐标）⭐

**显示内容**：
- X轴：投影仪列坐标（0-1919）
- Y轴：归一化幅值
- 红色虚线：最大峰值位置

**物理意义**：
- 这是**DFT变换后的完整频谱**
- X轴上的每个位置代表一个可能的投影仪坐标
- Y轴的值表示该坐标的可能性大小

**如何解读**：
```
理想情况（高质量）：
幅值
  |        █      ← 只有一个尖锐的主峰
 5|        █
  |       ███
  |      █████
  |_____███████_____ 投影仪坐标
      1230 1232

存在歧义（低质量）：
幅值
  |   █       █  ← 两个相近的峰值
 5|   █       █
  |  ███     ███
  |_███_______███___ 投影仪坐标
   500      1500
```

**关键信息**：
- **主峰位置** = 解码得到的投影仪坐标
- **主峰高度** = 解码质量（峰值强度）
- **是否有多个峰** = 是否存在歧义

---

#### 图5：完整频谱（对数坐标）

**与图4的区别**：
- Y轴改为对数坐标：log₁₀(幅值)
- **用途**：更清晰地显示**次要峰值**

**为什么需要对数坐标**：
```
线性坐标：
主峰太高，次要峰看不清
 10|   █
  8|   █
  6|   █
  4|   █        ← 次要峰被压扁，看不见
  2|   █  ▁  ▁
  0|___█__▁__▁____

对数坐标：
可以同时看到主峰和次要峰
  1|   █
  0|   █
 -1|   █  █
 -2|   █  █  █  ← 次要峰清晰可见
 -3|___█__█__█____
```

---

#### 图6：峰值局部放大

**显示内容**：
- 将图4中主峰附近的区域**放大显示**
- 范围：[峰值位置-100, 峰值位置+100]

**用途**：
- 查看主峰的**精细形状**
- 确认峰值是否尖锐
- 检查是否有相邻的干扰峰

---

#### 图7：峰值分析（改进版）⭐⭐⭐

**这是最重要的一张图！**

**显示内容**：
- X轴：**具体的投影仪坐标**（例如：1232, 1230, 1234...）
- Y轴：归一化幅值（峰值强度）
- 红色大圆点：最大峰值
- 蓝色折线：连接前20个最强的峰值
- 数值标签：前10个峰值的具体数值

**改进说明**：
- 之前需要**两张图**（图7峰值强度 + 图8峰值位置）才能理解
- 现在**一张图**就包含了所有信息！

**如何解读**：

**场景1：高质量解码**
```
峰值分析图：

强度
  |     ●  ← 1232: 4.90 (红色)
 5|    
  |    
 2|   ●  ● ← 1230和1234: 约2.0 (蓝色)
  |  ●    ●
  |___________→ 投影仪坐标
   1220  1232  1240

✅ 结论：
  - 峰值集中在1232附近
  - 最大峰值远高于其他峰值
  - 解码可靠，投影仪X坐标 = 1232
```

**场景2：存在歧义**
```
峰值分析图：

强度
  |  ●           ●  ← 两个相近的强峰值！
 5|
  |
 2|
  |
  |___________→ 投影仪坐标
   500    1000   1500

⚠️ 结论：
  - 峰值分散在500和1500
  - 存在多解歧义
  - 解码不可靠，需要额外信息
```

**场景3：低质量信号**
```
峰值分析图：

强度
  | ● ● ● ● ● ●  ← 所有峰值都很低
 1|
  |
  |___________→ 投影仪坐标
    分散的位置

❌ 结论：
  - 所有峰值强度都低于1.0
  - 信号太弱，不可靠
  - 可能是阴影/遮挡区域
```

**快速判断标准**：
1. **看峰值位置**：是否集中？
   - ✅ 集中在一个区域（如1230-1240）→ 好
   - ❌ 分散在多个区域（如500和1500）→ 差

2. **看最大峰值**：是否足够高？
   - ✅ > 1.0 → 质量好
   - ⚠️ 0.5-1.0 → 质量中等
   - ❌ < 0.5 → 质量差

3. **看峰值比例**：主峰是否远大于次峰？
   - ✅ 主峰/次峰 > 2 → 非常可靠
   - ⚠️ 主峰/次峰 < 1.5 → 可能有歧义

### 1️⃣ disparity_ver.png - 垂直视差图

这张图包含**两个子图**：

#### 左图：垂直视差图（投影仪列坐标）

**显示内容**：
- 彩色图像，颜色表示投影仪列坐标
- 色条范围：0（蓝色）→ 1919（红色）
- 白色区域：被过滤掉的低质量像素（peak < 0.5）

**如何解读颜色**：
```
颜色条：
红色 (1750-1920)  ← 投影仪右侧
↑
橙色 (1250-1750)
↑
黄色 (1000-1250)  ← 投影仪中间
↑
绿色 (750-1000)
↑
青色 (500-750)
↑
蓝色 (0-500)      ← 投影仪左侧
```

**物理意义**：
- **颜色渐变平滑** → 表面连续，深度变化平缓 ✅
- **颜色突变** → 深度不连续（物体边缘）
- **白色区域** → 无效区域（阴影、高光、背景）

**示例解读**：
```
从你的图来看：
- 左侧（X<500）：蓝色 → 投影仪坐标约0-500
- 中间（500<X<1500）：青-绿-黄渐变 → 投影仪坐标约500-1250
- 右侧（X>1500）：橙-红 → 投影仪坐标约1500-1920
- 白色区域（人像边缘、背景）：无效像素

✅ 渐变平滑，说明解码质量好
```

---

#### 右图：峰值强度图（质量图）

**显示内容**：
- 热力图，颜色表示峰值强度（解码质量）
- 色条范围：0（黑色）→ 2.0（白色/黄色）
- 标题显示：有效像素比例

**如何解读颜色**：
```
颜色含义：
白色/黄色 (>1.5)  ← 优秀质量
↑
橙色 (1.0-1.5)    ← 良好质量
↑
红色 (0.5-1.0)    ← 中等质量
↑
暗红 (0.25-0.5)   ← 较差质量
↑
黑色 (<0.25)      ← 很差/无效
```

**物理意义**：
- **亮色区域**（橙-黄-白）= 高质量区域 ✅
  - 表面平坦、反射良好
  - 垂直于投影方向
  - 无遮挡、无高光

- **暗色区域**（深红-黑）= 低质量区域 ❌
  - 阴影、遮挡
  - 镜面反射、高光
  - 物体边缘、深度不连续

**示例解读**：
```
从你的图来看：
- 物体中心区域：橙红色 → 质量中等到良好（0.5-1.0）
```

## 五、常见问题解答

### Q1：为什么峰值强度图（质量图）有很多黑色区域？

**A**: 黑色区域代表低质量或无效区域，主要原因：

1. **背景区域**：投影仪没有投影到（最常见）
2. **阴影区域**：被遮挡，没有接收到条纹
3. **高光区域**：镜面反射，信号饱和
4. **物体边缘**：深度不连续，信号混乱

**这是正常的！** 只要有效区域（物体表面）的峰值高，就说明解码成功。

---

### Q2：视差图中的颜色是什么意思？

**A**: 颜色表示**投影仪坐标**：

- **垂直视差图**：颜色 = 投影仪列坐标（X坐标，0-1919）
- **水平视差图**：颜色 = 投影仪行坐标（Y坐标，0-1079）

颜色从**蓝（小坐标）→ 绿 → 黄 → 橙 → 红（大坐标）**

**物理意义**：
- 相同颜色的像素点 → 对应相同的投影仪坐标 → 在3D空间中可能是同一深度
- 颜色渐变平滑 → 表面连续、深度变化平缓

---

### Q3：为什么statistics.png中很差的像素占比约50%？

**A**: 这是**正常现象**！

- 很差的像素（红色柱）主要是**背景区域**
- 场景中大约一半是背景，一半是物体
- 只要**优秀像素（绿色柱）占比高**，就说明物体区域解码质量好

**评判标准**：
- ✅ 优秀像素 > 40% → 质量很好
- ⚠️ 优秀像素 20-40% → 质量中等
- ❌ 优秀像素 < 20% → 质量较差，需要改进
