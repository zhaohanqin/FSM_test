### 第 3 页 · 问题背景：结构光为什么需要"解码"

- **版式**：上文字、下示意图。
- **标题**：结构光三维重建的核心难题
- **正文要点**：
  - 三维重建需要知道：每个相机像素对应投影仪上的哪个像素。
  - 相机拍到的只是物体表面反射回来的条纹图像，而不是投影仪坐标本身。
  - 因此必须有一个"解码"步骤，把相机看到的图像翻译回投影仪坐标。
  - 频移法（FSM / FSA）正是完成这一步的解码方法。
- **关键公式**：
  \[
  \text{相机像素 } (x_c, y_c) \;\longrightarrow\; \text{投影仪像素 } (x_p, y_p)
  \]
- **图示建议**：画"投影仪 → 物体表面 → 相机"的光路三角图，并用问号标注相机像素与投影仪像素之间的未知对应关系。

### 第 4 页 · 方法目标：两个方向分别解码

- **版式**：左右对照（水平条纹 / 垂直条纹）。
- **标题**：FSM 的目标 —— 分方向恢复投影仪坐标
- **正文要点**：
  - 把二维对应关系拆成两个方向独立解码。
  - **水平条纹 `hor`**：条纹沿水平延伸，灰度沿投影仪纵向变化，用于解码投影仪行坐标 \(y_p\)。
  - **垂直条纹 `ver`**：条纹沿垂直延伸，灰度沿投影仪横向变化，用于解码投影仪列坐标 \(x_p\)。
  - 解码主线输出四个文件：`disp_hor.npy`、`disp_ver.npy`、`peak_hor.npy`、`peak_ver.npy`。
  - `disp_*` 是投影仪坐标图，`peak_*` 是频谱峰值强度，用作解码质量 / 置信度。
- **图示建议**：左边一张水平条纹示意 + 标注 \(y_p\)，右边一张垂直条纹示意 + 标注 \(x_p\)；下方列出四个输出文件的小卡片。

### 第 5 页 · 为什么单张条纹图不够

- **版式**：上"问题"、下"两层序列方案"。
- **标题**：一张条纹图为什么不能定位
- **正文要点**：
  - 单张正弦条纹中，许多位置灰度相同 —— 无法唯一确定来自投影仪哪个位置。
  - 亮度还会受环境光、物体颜色、表面反射率、曝光、噪声干扰。
  - FSM 用"两层序列"解决：
    - 第一层：对每个频率投影多张相移图像（消除直流亮度干扰）。
    - 第二层：投影多个不同频率的条纹图像（形成频率轴信号）。
- **图示建议**：上方画一条正弦曲线，标出多个灰度相同的点说明"多义性"；下方用两个嵌套方框表示"频率序列 ⊃ 相移序列"的两层结构。

### 第 6 页 · 四步相移：构造复信号（上）

- **版式**：左公式推导、右作用说明。
- **标题**：四步相移 —— 从灰度到复数
- **正文要点**：
  - 当前解码默认每个频率有 4 张相移图像，相位为 0°、90°、180°、270°。
  - 图像命名按频率优先排列：`0,1,2,3` 是频率 0 的四相移，`4,5,6,7` 是频率 1，依此类推。
  - 对同一相机像素、同一频率，得到四个灰度值 \(I_0, I_1, I_2, I_3\)。
  - 由此构造差分信号与复信号。
- **关键公式**：
  \[
  D_c = I_0 - I_2,\qquad D_s = I_3 - I_1,\qquad D = D_c + j\,D_s
  \]
- **图示建议**：画 4 张相移图像缩略图标注相位角，箭头汇聚到一个复数 \(D\) 的"复平面点"。

### 第 7 页 · 四步相移：构造复信号（下）—— 为什么这样做

- **版式**：两点式要点 + 复平面示意。
- **标题**：四步相移差分的两个作用
- **正文要点**：
  - **作用一：抵消直流亮度。** \(I_0 - I_2\) 与 \(I_3 - I_1\) 会消掉大量共同亮度偏移，包括环境光、背景灰度、物体局部反射率。
  - **作用二：构造复信号。** \(D_c\) 近似余弦分量、\(D_s\) 近似正弦分量，组合成复数 \(D\)，让后续 FFT 能直接处理"相位随频率变化"的规律。
  - 关键结论：差分后，主要信息从"绝对灰度"转化为"复数相位"。
- **图示建议**：复平面上一个向量，分解为实部 \(D_c\)、虚部 \(D_s\)；旁边对比"原始灰度受干扰"与"差分后干扰被削弱"。

### 第 8 页 · 数学视角：投影强度模型

- **版式**：公式为主，配文字解释符号含义。
- **标题**：一个更具体的数学视角
- **正文要点**：
  - 把投影条纹写成随投影仪坐标 \(u\) 变化的正弦信号（\(f_k\) 为第 \(k\) 个投影频率，\(\phi\) 为相移）。
  - 相机看到的不是理想强度，而是经过反射、环境光、相机响应后的结果。
  - 符号含义：\(B(x_c,y_c)\) 是直流项（环境光、暗电流、背景亮度）；\(R(x_c,y_c)\) 是表面反射率与局部亮度缩放；\(u_p\) 是希望解码出的投影仪坐标。
- **关键公式**：
  \[
  I_{proj}(u, k, \phi) = A\,\sin(2\pi f_k u + \phi)
  \]
  \[
  I_{cam}(x_c, y_c, k, \phi) = B(x_c,y_c) + R(x_c,y_c)\,A\,\sin(2\pi f_k u_p + \phi)
  \]
- **备注**：强调四步相移差分会显著削弱 \(B\)，把主要信息转成与 \(2\pi f_k u_p\) 相关的复数相位；最终解码使用幅值谱 \(|C|\) 的峰值，所以核心机制不依赖正负号约定。

### 第 9 页 · 多频率：形成"频率轴信号"

- **版式**：上文字、下"频率轴"示意。
- **标题**：FSM 的核心 —— 看频率轴上的响应
- **正文要点**：
  - FSM 不只看某一个频率，而是看同一相机像素在一系列投影频率下的响应。
  - 对固定相机像素 \((x_c, y_c)\)，沿频率轴取出复数序列 \(D[0], D[1], \dots, D[M-1]\)。
  - 这个长度为 \(M\) 的复数序列，就是该像素的"频率响应信号"。
  - 关键规律：若该像素真实对应投影仪坐标 \(u\)，随投影频率递增，复数相位会按与 \(u\) 有关的速率旋转。
  - 即：投影仪坐标被编码成了**频率轴上的相位变化率**。
- **关键公式**：
  \[
  D[0],\; D[1],\; D[2],\; \dots,\; D[M-1] \quad (\text{长度为 } M \text{ 的复信号})
  \]
- **图示建议**：横轴为频率索引，画一串复平面小箭头逐步旋转，体现"相位随频率匀速旋转"。

---

### 第 10 页 · 从相位旋转到频谱峰值

- **版式**：左"旋转速度"、右"频谱峰值"。
- **标题**：为什么 FFT 能找出投影仪坐标
- **正文要点**：
  - 不同投影仪坐标 \(u_p\) → 不同的相位旋转速度。
  - 对频率轴信号做 DFT / FFT，就是在频域中寻找"旋转速度最匹配"的位置。
  - 当频率样本相位对齐时，能量集中，幅值出现峰值。
  - 因此：**频谱峰值位置 = 投影仪坐标**。
- **图示建议**：左边三组不同旋转速度的复向量序列，右边对应三条频谱曲线，峰值位置各不相同，用箭头一一对应。

### 第 11 页 · 单像素解码流程总览

- **版式**：四步横向流程图。
- **标题**：每个相机像素都做这四步
- **正文要点**：
  - 输入图像数组形状为 \((M\times 4,\ H_c,\ W_c)\)，第一维始终是"频率 × 相移"维度。
  - 解码可理解为对每个相机像素独立执行：
    1. 提取四个相移序列
    2. 构造频率轴复信号
    3. 沿频率维度做 FFT
    4. 取频谱峰值作为投影仪坐标
- **图示建议**：四个带编号的方块用箭头串联，方块下方标注每步输出的数据形状。
- **备注**：本页作为后面四页的"导航总览"。

### 第 12 页 · 步骤 1：提取四个相移序列

- **版式**：左代码片段、右数据形状说明。
- **标题**：步骤 1 —— 按相位重新分组
- **正文要点**：
  - 用切片把图像按相位重新分组：`I0 = images[0::4]`、`I1 = images[1::4]`、`I2 = images[2::4]`、`I3 = images[3::4]`。
  - 分组后 \(I_0/I_1/I_2/I_3\) 形状都是 \((M,\ H_c,\ W_c)\)。
  - 对任意相机像素 \((x,y)\)，`I0[:, y, x]` 就是该像素在全部频率下的 0° 相移灰度序列。
- **图示建议**：一长条 \(M\times 4\) 的图像堆叠，用四种颜色间隔标出 0°/90°/180°/270°，分流成四个 \(M\) 长的子堆叠。

### 第 13 页 · 步骤 2：构造频率轴复信号

- **版式**：公式 + 数据形状。
- **标题**：步骤 2 —— 实数灰度变复数序列
- **正文要点**：
  - 代码构造 \(D_c = I_0 - I_2\)、\(D_s = I_3 - I_1\)、\(D = D_c + jD_s\)。
  - \(D\) 形状仍是 \((M,\ H_c,\ W_c)\)，但每个像素位置已从实数灰度序列变成复数频率响应序列。
  - 对单个像素：`D[:, y, x]` = 该相机像素沿频率轴的一维复信号。
- **关键公式**：
  \[
  D[:, y, x] \;=\; \text{相机像素 }(x,y)\text{ 沿频率轴的一维复信号}
  \]
- **图示建议**：把"实数灰度立方体"映射成"复数立方体"，单个像素位置抽出一条复信号曲线。

---

### 第 14 页 · 步骤 3：沿频率维度做 FFT

- **版式**：左公式、右"轴方向"强调。
- **标题**：步骤 3 —— FFT 沿频率轴，不是沿图像空间
- **正文要点**：
  - 主线代码按图像块处理：`C = np.fft.fft(D_block, n=fft_length, axis=0)`，`C_magnitude = np.abs(C)`。
  - `axis=0` 表示 FFT 沿频率维度执行，**不是**对图像做二维傅里叶变换。
  - 即：对每个相机像素自己的频率响应序列做一维 FFT。
  - 当 \(k\) 与该像素对应的投影仪坐标一致时，各频率样本相位对齐，幅值 \(|C[k]|\) 最大。
- **关键公式**：
  \[
  C[k] = \sum_{m} D[m]\,\exp\!\left(-j\,\frac{2\pi k m}{N}\right)
  \]
- **图示建议**：一个三维数据块，用红色箭头明确标注 FFT 沿"频率轴（axis=0）"方向，与"图像行列轴"形成对比。

### 第 15 页 · 步骤 4：取频谱峰值作为投影仪坐标

- **版式**：左公式、右输出含义。
- **标题**：步骤 4 —— 峰值即坐标，峰高即置信度
- **正文要点**：
  - 主线代码：`freq_index = np.argmax(C_magnitude, axis=0)`，`peak = np.max(C_magnitude, axis=0) / fft_length`。
  - `freq_index`：每个相机像素频谱最大峰值的位置。
  - `peak`：最大峰值强度，经 `fft_length` 归一化，用作质量评价。
  - 坐标映射：当 `coord_scale == 1.0` 时 `disparity = freq_index`；否则 `disparity = freq_index * coord_scale`。
- **关键公式**：
  \[
  \text{disparity} =
  \begin{cases}
  \text{freq\_index}, & \text{coord\_scale} = 1.0\\[4pt]
  \text{freq\_index} \times \text{coord\_scale}, & \text{otherwise}
  \end{cases}
  \]
- **图示建议**：一条频谱曲线标出 argmax 峰值位置，箭头指向"投影仪坐标图"中的对应像素值。

### 第 16 页 · 单像素等价伪代码

- **版式**：整页代码块 + 一句结论。
- **标题**：把整个流程压缩成一段伪代码
- **正文要点（伪代码）**：
  ```python
  signal = []
  for f in range(M):
      I0 = image[4*f + 0][y, x]
      I1 = image[4*f + 1][y, x]
      I2 = image[4*f + 2][y, x]
      I3 = image[4*f + 3][y, x]
      Dc = I0 - I2
      Ds = I3 - I1
      signal.append(Dc + 1j * Ds)

  C = fft(signal, n=fft_length)
  coord   = argmax(abs(C))
  quality = max(abs(C)) / fft_length
  ```
- **核心结论（高亮）**：FSM 解码不是在一张图里找条纹位置，而是对"同一相机像素随投影频率变化形成的复信号"做频谱分析。
- **备注**：本页是全片的"逻辑收口"，建议放在原理讲解段落的末尾。

### 第 17 页 · FFT 长度策略（关键实现细节）

- **版式**：左右两分支对照。
- **标题**：FFT 长度怎么选 —— `_get_fft_params()`
- **正文要点**：
  - 投影仪对应维度：`hor` 用投影仪高度，`ver` 用投影仪宽度（记为 `proj_dim`）。
  - **分支一 `frequency_step == 1.0`（标准模式）**：`fft_length = proj_dim`，`coord_scale = 1.0`，argmax 直接输出投影仪坐标。
  - **分支二 `frequency_step != 1.0`**：`fft_length = M`，`coord_scale = proj_dim / M`，argmax 后需坐标映射。
  - `coord_scale` 的含义：频谱 bin 到投影仪像素坐标的换算比例。
- **关键公式**：
  \[
  \text{coord\_scale} = \frac{\text{proj\_dim}}{M} \quad (\text{当 frequency\_step} \neq 1.0)
  \]
- **图示建议**：一个判断分叉流程图，两条分支分别标注 fft_length 与 coord_scale 的取值。

### 第 18 页 · 为什么错误的 FFT 长度会产生量化阶梯

- **版式**：上"错误做法"、下"正确做法"对照。
- **标题**：FFT 长度设错 → 三维重建出现量化阶梯
- **正文要点**：
  - 若在标准模式下错误使用 `fft_length = M`，频谱只有 \(M\) 个 bin。
  - 例：投影仪宽度 1920、采集频率数 340，则每个 bin 约对应 \(1920/340 \approx 5.65\) 个投影仪像素。
  - argmax 只能返回整数索引，乘以 5.65 后视差只能取 0、5.65、11.29、16.94 …… 这种离散值。
  - 离散化会传递到三维重建，在点云深度上表现为"量化阶梯"。
  - 恢复"FFT 长度 = 投影仪分辨率"后，标准模式视差最小步长回到 1 个投影仪像素，阶梯明显减轻。
- **关键公式**：
  \[
  \frac{1920}{340} \approx 5.65 \ \text{个投影仪像素 / bin}
  \]
- **图示建议**：左边一条阶梯状的深度曲线（错误），右边一条平滑深度曲线（正确）。

### 第 19 页 · 标准模式下 M 为什么可以小于投影仪分辨率

- **版式**：文字 + 零填充示意。
- **标题**：零填充 —— 用投影仪坐标尺度采样频谱
- **正文要点**：
  - 实验中 `NUM_FREQUENCIES` 可能只有 151，远小于投影仪宽高（如 1920 / 1080）。
  - 关键在 `np.fft.fft(D_block, n=fft_length, axis=0)`：当 `fft_length > M` 时，NumPy 在序列后补零。
  - 补零后的 FFT 给出更多频谱采样点，让峰值位置能在投影仪分辨率尺度上表达。
  - 注意：零填充**不增加**原始采集信息，不能替代更密集采集或亚像素估计；它的价值是避免把输出强行量化到 \(M\) 个粗 bin 上。
  - 更准确的说法："FFT 长度使用投影仪分辨率" = "用投影仪像素坐标尺度采样频谱峰值位置"。
- **图示建议**：一段 \(M\) 长的信号后面接一段灰色"补零区"，FFT 后频谱采样点变密。

### 第 20 页 · 工程实现：分块处理与低内存模式

- **版式**：左右两栏（标准分块 / 低内存）。
- **标题**：在速度与内存之间取舍
- **正文要点**：
  - **标准分块模式**：把图像按 `block_size`（如 100×100）切块，对块内所有像素同时做 FFT，速度快；内存峰值来自 `D_block`、`C`、`C_magnitude`。
  - **低内存模式 `_decode_direction_low_memory()`**：逐行处理，每次只保留一行的频率响应，再逐像素 FFT。
  - 取舍：低内存模式显著降低中间频谱数组的内存峰值，但逐像素循环更多、通常更慢。
  - 建议：内存足够时优先标准模式；内存不足时再打开 `LOW_MEMORY_MODE = True`。
- **图示建议**：左边一张图被网格切成小块逐块处理；右边同一张图被一行一行扫描处理。
- **备注**：可附一条计算量估算 —— FFT 环节约为 \(O(H_c W_c \cdot \text{fft\_length} \cdot \log(\text{fft\_length}))\)。

### 第 21 页 · 图像缓存机制

- **版式**：简单流程图 + 文字。
- **标题**：图像缓存 —— 把重复磁盘读取换成一次数组读取
- **正文要点**：
  - 由 `ImageLoader.load_images()` 实现，默认缓存路径为输入目录下的 `images_cache.npy`。
  - 逻辑：若启用缓存且缓存存在，直接 `np.load`；否则读完图像后 `np.save` 写缓存。
  - 一次解码需读取 \(M\times 4\) 张图像，同时解码水平和垂直方向时读取量翻倍。
  - 缓存不改变算法结果，只是把大量小图像文件的重复解码与磁盘读取，转换成一次 `.npy` 数组读取，便于反复调试 FFT 参数、多峰扫描、极线校正。
- **图示建议**：判断框"缓存存在？" → 是 → 读 `.npy`；否 → 读图像文件 → 写 `.npy`。

### 第 22 页 · 多峰检测：当频谱不只一个峰

- **版式**：上"问题场景"、下"多峰检测逻辑"。
- **标题**：多峰检测 —— 处理误匹配的第一级后处理
- **正文要点**：
  - 理想情况下每个像素频谱只有一个主峰，`argmax` 即正确坐标。
  - 但实际可能出现多个显著峰值：高反光区混合反射、遮挡边界混合信号、多路径干扰、噪声 / 低纹理降低主峰优势。
  - `MultiPeakDetector.find_peaks()` 遍历归一化频谱：先用阈值 `limit` 去弱峰，再用左右邻域判断局部极大值，距离小于 `merge_distance` 的近峰按幅值加权合并。
  - 输出的是一组**候选**投影仪坐标，而非最终坐标。
- **关键公式（近峰加权合并）**：
  \[
  k_i = \frac{v}{v + v_{prev}},\qquad
  \text{new\_pos} = k_i \cdot i + (1 - k_i)\cdot \text{prev\_pos}
  \]
- **图示建议**：一条有两三个明显峰的频谱曲线，标出主峰与次峰，并示意近峰合并。

### 第 23 页 · 极线约束校正：用几何选出正确匹配

- **版式**：左原理图、右公式。
- **标题**：极线约束校正 —— 第二级后处理
- **正文要点**：
  - `EpipolarCorrector` 用相机与投影仪标定参数构造投影矩阵，计算相机像素在投影仪图像中的极线。
  - 把水平、垂直方向的候选峰做组合：候选点 \((p_x, p_y) = \text{peaks\_ver} \times \text{peaks\_hor}\)。
  - 计算每个候选点到投影仪极线的距离，距离最小者被认为更符合双目几何约束。
  - 校正结果保存为 `disp_hor_corrected.npy`、`disp_ver_corrected.npy`。
  - 多峰检测与极线校正是**可选后处理**，不替代主解码：`argmax` 全图批量、速度快、流程稳定，适合作默认输出；后处理依赖标定参数，更适合定位与修正少量可疑像素。
- **关键公式**：
  \[
  d = \frac{\lvert a x + b y + c \rvert}{\sqrt{a^2 + b^2}}
  \]
  其中投影仪图像中的极线方程为 \(a x + b y + c = 0\)。
- **图示建议**：投影仪图像平面上画一条极线，散布若干候选点，距离最近的点高亮为"正确匹配"。

### 第 24 页 · 解码质量评估与误差来源

- **版式**：上"峰值分级表"、下"常见误差表"。
- **标题**：怎么判断解码质量、怎么排查问题
- **正文要点**：
  - 质量指标定义：\(\text{peak} = \max(|C|) / \text{fft\_length}\)，反映主峰强度；主峰越高、次峰越低，投影仪坐标越明确。
  - **峰值强度经验分级**（阈值需结合数据集调整，非物理判据）：
    - \(\text{peak} > 1.0\)：主峰明显，信号较强，通常可优先保留。
    - \(0.5 < \text{peak} \le 1.0\)：信号中等，建议结合点云与频谱图检查。
    - \(\text{peak} \le 0.5\)：信号较弱，易误匹配，可考虑过滤或重点诊断。
  - **常见误差来源**：标定误差、投影仪光学畸变、相机曝光不当、表面反光 / 多路径、遮挡边界、条纹序列顺序错误、FFT 长度设置不合理。
- **图示建议**：用两个并排的表格分别呈现"峰值分级"与"误差来源 → 表现 → 缓解方式"。
- **备注**：可附简短排查顺序 —— 先查图像数量与命名 → 启用 `VERIFY_SEQUENCE` → 看 `peak_*.npy` → 对异常点设 `SPECTRUM_POINTS` 查频谱 → 必要时多峰扫描与极线校正 → 点云呈台阶则查 `FREQUENCY_STEP` 与 FFT 长度。

### 第 25 页 · 与三维重建的关系 + 完整数据流

- **版式**：上"对应关系公式"、下"纵向数据流图"。
- **标题**：FSM 在三维重建管线中的位置
- **正文要点**：
  - FSM 解码本身不直接输出三维点云，它输出的是相机像素到投影仪像素的二维对应关系。
  - 后续 `FSM_reconstruct_*` 读取这些对应关系，结合相机—投影仪标定参数做三角化生成点云；`peak_*.npy` 可用于过滤低质量像素。
- **关键公式**：
  \[
  x_p = \text{disp\_ver}[y_c, x_c],\qquad
  y_p = \text{disp\_hor}[y_c, x_c]
  \]
- **数据流（建议做成纵向流程图）**：
  投影多频率多相移条纹 → 相机采集水平 / 垂直条纹序列 → 按频率与相位整理为 `0,1,2,3,…` → `FSM_decode_example.py` 读配置并调用 `FSADecoder` → `ImageLoader` 加载 \(M\times 4\) 张图像 → 提取 \(I_0/I_1/I_2/I_3\) → 构造 \(D = (I_0-I_2) + j(I_3-I_1)\) → 每个相机像素沿频率轴做 FFT → 取频谱最大峰值作为投影仪坐标 → 保存 `disp_* / peak_*` → 可选频谱分析、多峰扫描、极线校正 → 三维重建三角化生成点云。
- **图示建议**：纵向箭头串联的流程图，可选后处理用虚线分支表示。

### 第 26 页 · 总结

- **版式**：要点收束页。
- **标题**：核心要点回顾
- **正文要点**：
  - FSM 的本质：把投影仪坐标编码为"频率轴上的相位变化率"，再用 FFT 解出来。
  - 四步相移消除直流亮度干扰并构造复信号；多频率序列构成可被 FFT 分析的频率轴信号。
  - 单像素解码四步：提取相移序列 → 构造复信号 → 沿频率轴 FFT → 取峰值作为坐标。
  - FFT 长度策略是关键实现细节：标准模式下 `fft_length = 投影仪分辨率`，避免量化阶梯。
  - 工程上用分块 / 低内存模式平衡速度与内存，用缓存加速重复调试。
  - 多峰检测与极线约束校正是可选后处理，用于定位和修正复杂反射 / 遮挡区域的误匹配。
  - FSM 的输出是相机—投影仪对应关系，是三维重建三角化的输入。
- **图示建议**：把全片主线浓缩成一条"条纹图像 → 复信号 → 频率轴 → FFT → 投影仪坐标 → 点云"的极简横向图。
