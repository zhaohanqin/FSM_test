## 一、误差计算的原理与过程，及终端日志含义

### 1.1 核心原理

程序采用的误差度量方式是：**点到最近邻点的欧氏距离（Point-to-Point Nearest Neighbor Distance）**。

对于待比较点云中的每一个点，我们需要知道它"离基准点云有多远"。由于两个点云的采样点位置一般**不完全重合**（即使描述同一个物体，不同扫描角度、分辨率、噪声都会导致点的位置不同），无法做一一对应的直接相减，因此采用以下策略：

> 对待比较点云中的每个点 $p_i$，去基准点云里**找距离它最近的那个点** $q_i^*$，把这两点之间的距离定义为 $p_i$ 的误差值 $e_i$。

### 1.2 完整计算过程（三步）

#### 第一步：构建 KD-Tree（对应日志：`正在构建 KD-Tree（基准点云）...`）

**KD-Tree**（K-Dimensional Tree，K 维树）是一种专门用于高维空间**快速最近邻检索**的数据结构。

构建过程如下：

- 将基准点云的全部 $M$ 个点按照空间坐标（X / Y / Z）递归地划分，每次选择方差最大的坐标轴，以中位数为切割面将当前点集一分为二，重复此过程直到每个叶节点只包含少量点。
- 构建完成后，整个三维空间被切分为一个个小区块，所有点被组织成一棵平衡二叉树。

```
基准点云 M 个点
        │
        ▼
┌───────────────┐
│  KD-Tree 构建 │  ← 按 X/Y/Z 轴递归空间分割
└───────────────┘
        │
        ▼
    空间索引树（只构建一次，供后续 N 次查询复用）
```

**这一步的含义**：把基准点云的空间结构"预先整理好"，使得后续对每个待比较点的最近邻搜索可以大幅加速，无需遍历全部 $M$ 个基准点。

---

#### 第二步：最近邻查询（对应日志：`正在查询最近邻距离...`）

对待比较点云中的每一个点 $p_i$（共 $N$ 个），利用已构建好的 KD-Tree 执行最近邻搜索：

1. 从根节点出发，沿树向下走到离 $p_i$ 最近的叶节点区域。
2. 记录当前最短距离，然后**回溯**，判断相邻分支是否可能存在更近的点（若当前最短距离的球体不与相邻分支的区域相交，则该分支可被剪枝跳过）。
3. 找到最终的最近邻点 $q_i^*$，计算两点距离作为误差 $e_i$。

| 搜索方法 | 单次查询复杂度 | $N$ 次查询总复杂度 |
|:---:|:---:|:---:|
| 暴力枚举（不用 KD-Tree） | $O(M)$ | $O(N \cdot M)$ |
| KD-Tree 查询 | $O(\log M)$（平均） | $O(N \log M)$ |

对于典型的百万级点云，KD-Tree 方案比暴力枚举快约 **3～4 个数量级**。

**这一步的含义**：对待比较点云中的每一个点，快速找到基准点云中离它最近的点，并记录两者之间的三维直线距离，作为该点的误差值。

---

#### 第三步：汇总误差数组，统计指标

$N$ 次查询完成后，得到误差数组：

$$
\mathbf{e} = [e_1,\ e_2,\ \ldots,\ e_N]
$$

基于此数组分两块统计：

**统计块 1（全体点，$N$ 个）**

$$
\text{Mean} = \frac{1}{N}\sum_{i=1}^{N} e_i, \quad
\text{Max} = \max_i e_i, \quad
\text{Min} = \min_i e_i
$$

$$
\text{RMSE} = \sqrt{\frac{1}{N}\sum_{i=1}^{N} e_i^2}, \quad
\text{Std} = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(e_i - \bar{e})^2}
$$

**统计块 2（仅差异点，$e_i > \tau$ 的 $K$ 个点）**

$$
\text{Diff Mean} = \frac{1}{K}\sum_{i \in D} e_i, \quad
\text{RMSE}_D = \sqrt{\frac{1}{K}\sum_{i \in D} e_i^2}
$$

$$
\text{Std}_D = \sqrt{\frac{1}{K}\sum_{i \in D}(e_i - \bar{e}_D)^2}, \quad
\text{P95}_D = \text{percentile}_{95}(\{e_i \mid e_i > \tau\})
$$

---

### 1.3 整体流程图

```
待比较点云（N 个点）          基准点云（M 个点）
        │                           │
        │                    构建 KD-Tree
        │                           │
        ▼                           ▼
  逐点 p_i  ──── KD-Tree 查询 ───→  找最近邻 q_i*
        │
        ▼
  e_i = ||p_i - q_i*||_2   （欧氏距离）
        │
        ▼
  误差数组 [e_1, e_2, ..., e_N]
        │
   ┌────┴────┐
   ▼         ▼
统计块1    统计块2
（全体点）  （差异点 e_i > τ）
```

## 二、欧氏距离误差是什么

### 2.1 定义

**欧氏距离（Euclidean Distance）** 是数学上对"两点之间直线距离"的精确表达，也是我们在日常三维空间中感知的普通距离。

在三维空间中，对于待比较点 $p_i = (x_p,\ y_p,\ z_p)$ 和基准点云中的最近邻点 $q_i^* = (x_q,\ y_q,\ z_q)$，欧氏距离为：

$$
e_i = \|p_i - q_i^*\|_2 = \sqrt{(x_p - x_q)^2 + (y_p - y_q)^2 + (z_p - z_q)^2}
$$

### 2.2 几何直观

```
          p_i (待比较点)
           ●
          /|
         / |  ← e_i = 直线段长度（三维空间中的直线距离）
        /  |
       ●───┘
      q_i* (基准点云中的最近邻点)
```

**用一句话概括**：$e_i$ 就是在三维空间中，待比较点 $p_i$ 到基准点云表面上距它最近那个点 $q_i^*$ 的**直线段长度**。

### 2.3 物理含义

| $e_i$ 大小 | 含义 |
|:---:|:---|
| $e_i \approx 0$ | 该点与基准点云几乎完全吻合，几乎无偏差 |
| $e_i$ 较小（$\leq \tau$） | 该点在允许误差范围内，视为正常点 |
| $e_i$ 较大（$> \tau$） | 该点偏离基准点云超过误差限，视为**差异点**，标注红色 |

### 2.4 为什么选用欧氏距离

- **直观**：与工程领域中"偏差量"的概念一致，单位与坐标单位相同。
- **对称**：$\|p - q\|_2 = \|q - p\|_2$，方向无关。
- **计算高效**：配合 KD-Tree，大规模点云也可快速完成。
- **广泛采用**：是点云质量检测、逆向工程、3D 打印检验等领域的主流误差度量方式。

## 三、误差限 THRESHOLD 的单位

### 3.1 核心结论

> **`THRESHOLD` 的单位与 `.ply` 文件中点云坐标值的单位完全一致。**  
> 程序本身不附加任何物理单位，`THRESHOLD = 1.0` 意味着"1.0 个坐标单位的距离"。

### 3.2 各场景对应关系

| 点云来源 / 坐标单位 | `THRESHOLD = 1.0` 的含义 | 推荐取值范围 |
|:---|:---:|:---:|
| 工业三维扫描仪（单位：毫米 mm） | 1.0 毫米 | 0.1 ～ 5.0 |
| 激光雷达（LiDAR，单位：米 m） | 1.0 米 | 0.01 ～ 0.5 |
| 摄影测量点云（单位：米 m） | 1.0 米 | 0.005 ～ 0.1 |
| 归一化点云（坐标在 \[-1, 1\] 内） | 无量纲 1.0 个单位 | 0.01 ～ 0.1 |
| 医疗 CT / MRI（单位：毫米 mm） | 1.0 毫米 | 0.5 ～ 3.0 |

### 3.3 如何判断自己点云的坐标单位

**方法一：查看坐标值范围**

用 MeshLab 或 CloudCompare 打开点云，观察坐标轴的数值范围：

```
X 轴范围 [-0.3, 0.3]  →  单位大概率是米（m）
X 轴范围 [-300, 300]  →  单位大概率是毫米（mm）
X 轴范围 [-1, 1]      →  归一化处理过，无量纲
```

**方法二：查阅扫描仪参数文档**

不同品牌的三维扫描仪输出文件的默认单位不同，可查阅设备说明书或点云采集软件的导出设置。

**方法三：结合实际尺寸换算**

若已知被扫描物体的真实尺寸（例如一个边长 20 cm 的正方体），在点云中测量对应距离，即可推算坐标单位。

### 3.4 设置建议

```python
# 工业零件检测（坐标单位：毫米）
THRESHOLD = 0.1      # 允许 0.1 mm 误差

# 建筑 BIM 点云（坐标单位：米）
THRESHOLD = 0.02     # 允许 2 cm 误差

# 自动驾驶 LiDAR 地图（坐标单位：米）
THRESHOLD = 0.05     # 允许 5 cm 误差

# 医疗器械（坐标单位：毫米）
THRESHOLD = 0.5      # 允许 0.5 mm 误差
```

> **建议**：在正式分析前，先将 `THRESHOLD` 设置为一个较大的值（如坐标范围的 1%～5%），观察差异点分布是否符合预期，再逐步收紧到实际工程要求的精度值。

